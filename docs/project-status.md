## 初步推荐方案（尚未确认实施）

优先在现有工程上渐进适配，复用播放、弹幕、字幕和媒体库核心。备选为独立 TV 应用模块；若投影固件不提供可行安装途径，再考虑外接 Android TV 设备。

1. 先定位安装失败原因，区分系统安装策略、APK 解析、ABI、签名冲突与启动入口问题。
2. 打通启动 → 媒体库 → 视频 → 弹幕 → 播放 → 保存进度的最小流程。
3. 验证并补齐所有核心页面的遥控器焦点、确认／返回行为及可操作性。
4. 根据投影观看距离调整横屏显示、文字、弹幕和字幕预设。
5. 真机验证硬件解码、常用格式、字幕、密集弹幕及长时间稳定性。

首轮不同时替换播放内核或整体升级工具链。独立 TV 包名、固定签名等仍属于待确认设计，不是已作出的实施决定。
